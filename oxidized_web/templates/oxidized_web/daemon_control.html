Daemon Operations
Reload Configuration & Nodes

Sends a SIGHUP signal to the running daemon to reload settings, OS models, and node inventory from PostgreSQL without dropping active connections.

Restart Daemon Process

Sends a SIGTERM signal to gracefully terminate the running daemon process. If running under systemd or supervisor, it will automatically restart with fresh memory and configuration.
